Strengths: In our September 15 synthetic MOSAIC rehearsal, GitHub Copilot App loaded the repository skill and successfully used both read-only MCP tools: listing four approved evidence sources and reading the selected security standard. The archived App screenshot and returned payloads preserve source IDs, classifications, revisions and content hashes. This made the evidence boundary visible in the same workspace as the task and showed how reusable instructions and connected context can support governed field work.

Limitations encountered: Our selected custom agent initially did not expose the registered tools because its tool allowlist needed correction. The friction was distinguishing server registration from the agent's effective permissions; this was our configuration error, not an established App defect. The capture's build was not recorded. Installed version 1.1.21 was observed separately later that day and is not presented as the capture's version. This observation does not establish multi-agent performance or a complete issue-to-review workflow.

Suggested improvement: Surface a task-specific effective-tool view beside the selected agent, showing registered tools, tools actually available to that agent, and the permission or configuration layer that blocks each unavailable tool. Link each explanation to the relevant setting and suggest the narrowest correction, without broadening permissions automatically. Make this diagnostic context easy to include in a reviewable session summary with the tool arguments, source IDs and results. This is a proposed usability improvement grounded in our troubleshooting experience, not a claim that every related diagnostic is absent from the product.
